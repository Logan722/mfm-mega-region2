    How it runs

    Built to keep going without your laptop.

    Each piece runs on a service that is always on. You approve the MFM fact sheet once; after that new questions, prayer points and the leaderboard look after themselves.

    In the page itself

    Daily quiz

    A new set of five every day at midnight CT, the same for everyone. Nothing has to run for it to change.

    Netlify (comes with the site)

    Leaderboard

    Scores checked on the server, one score per device per day, nickname filter. Branch totals reset every Monday by themselves.

    Claude cloud scheduled task

    New questions weekly

    Reads last week’s messages, Pastor Oni’s 17 books and the approved fact sheet; every question carries its source and is rejected if the answer isn’t in it.

    Same weekly task

    Prayer points & declarations

    Prayer-point pages for HD and OHE, the homepage declaration, and the newsletter quiz section.

    GitHub (already every 30 min)

    Site rebuild

    The existing sync keeps media, events and the calendar feed up to date.

    Plausible analytics

    Know what works

    On every page, counting sign-ups, quiz plays, shares and prayer requests, with numbers in the weekly report.
